# LegacyPilot v0.2.0

LegacyPilot v0.2.0 turns the v0.1 vertical slice into a recoverable and governed single-agent harness. It keeps the original Java change workflow while making long runs, external writes, model fallback, retrieval state and Docker dependencies auditable and fail-closed.

## Highlights

- Versioned durable state with v0.1 migration, atomic replacement and damaged-state quarantine
- Persistent Action Journal, stable action IDs and `NEEDS_REVIEW` for uncertain write outcomes
- Run lease with owner/epoch/TTL fencing and recovery coordination
- Append-only persistent trace and bounded task memory with deterministic context compaction
- Versioned Policy DSL with deterministic deny/approval/allow precedence
- Short-lived, scoped, one-time capability grants for governed MCP writes
- Model profiles, shared budgets, bounded transient fallback and provider circuit breaker
- Revision/model/file-digest scoped vector store, reranker and explicit lexical degradation
- Networked Maven dependency prewarm followed by read-only-cache, no-network execution
- MCP initialization reports the packaged implementation version instead of a stale hard-coded value

## Compatibility and migration

- Java 21 and Maven Wrapper remain required.
- v0.1 state is migrated into the schema-v2 envelope; unknown future versions fail closed.
- Existing read-only MCP clients remain compatible. Write tools require explicit policy permission and a matching capability.
- Docker execution now separates trusted dependency prewarm from offline execution. Existing cache paths should be recreated through the provisioner.
- See [v0.1 → v0.2 migration](../MIGRATION_V0.2.md).

## Known limitations

- The durable stores and leases target a local/single-node deployment, not a distributed scheduler.
- Capability issuance is an application-level security primitive, not enterprise identity or SSO.
- The local vector store is revision-scoped but not a hosted multi-tenant vector service.
- Provider fallback is bounded and deterministic by profile; it does not perform autonomous model shopping.
- Application Docker Compose/PostgreSQL deployment remains deferred; Docker is used for the Maven sandbox.
- The public real-model dataset still contains five Banking tasks. Dataset expansion and experiment comparison are the focused v0.3 scope.

## Next direction

The focused v0.3 plan expands the dataset to 20 core tasks, adds resumable provider-backed experiments, paired model/Prompt/strategy comparisons, explicit failure classification and a self-contained static results dashboard. It deliberately avoids a general AgentOps platform.
