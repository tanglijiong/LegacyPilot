# LegacyPilot v0.1.0

LegacyPilot v0.1.0 proves a controlled end-to-end change loop for enterprise Java systems: code indexing and retrieval, impact analysis, approval, isolated production-code edits, Maven verification, retry budgets, trace and auditable reports.

## Evidence

- Dataset: `v0.1`, Banking fixture `banking-fixture-v2`
- Real-model baseline: GPT-5.4, reasoning `high`, `baseline-prompt-v1`, `codex-agent-v1`
- First attempt: 1/5; after at most one public-assertion feedback retry: **5/5**
- API-equivalent estimate: `$1.276451`
- Clean-environment Quickstart: **16m12s**, below the 30-minute target
- Final verification: **127 tests**, 0 failures, 0 errors, 0 skipped
- Real Docker integration tests: **2/2 passed**
- Release commit CI, Security and Eval smoke: passed

The first-attempt result is intentionally retained. Reference solutions were never exposed to the model, fixture tests and `pom.xml` remained unchanged, and reference ceiling is not reported as model performance.

## Included capabilities

- Java 21 Maven multi-module application with CLI and Spring Boot API
- Git worktree isolation and guarded File/Git/Patch/Maven tools
- Docker Maven sandbox with resource, mount and network boundaries
- JavaParser symbols, exact/BM25/dependency-graph retrieval and token budgeting
- Provider-independent Model Gateway and Spring AI adapter
- Plan → Act → Observe → Verify loop with approval and bounded retry
- Markdown/JSON report, structured trace, metrics and sensitive-data redaction
- STDIO Java Project MCP and five-task deterministic Eval Harness

## Known limitations

- Official support is Java 21 + Maven; Gradle and other languages are not release targets.
- MCP uses STDIO and the implemented initialize/tools subset; HTTP transport, resources and prompts are out of scope.
- Provider-backed runs remain subject to model alias drift, rate limits and transport instability.
- The application uses a local single-process/H2 development path. PostgreSQL/pgvector Compose deployment is deferred.
- This release does not automatically push, open PRs or merge changes into user repositories.

## Next direction

v0.2 strengthens the same single-agent harness with durable recovery, Action Journal, leases, task memory, policy DSL, scoped capabilities, governed MCP writes, model fallback/circuit breaking, revision-scoped vector retrieval and offline Docker dependency caching.
